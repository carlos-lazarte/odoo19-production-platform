# Security Policy

## Scope

This repository documents and automates a production-oriented Odoo 19 deployment. It may contain configuration templates and operational scripts.

## Do not commit

- Passwords or password hashes
- API tokens
- Private keys
- TLS private material
- Database dumps
- Filestore contents
- Personal data
- Environment-specific secrets

Use placeholders, environment variables or a dedicated secret-management mechanism instead.

## Reporting

Do not publish sensitive security details in a public issue. Report suspected vulnerabilities privately to the repository maintainer through an appropriate GitHub private channel.
